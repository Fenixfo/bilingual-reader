# bilingual-reader

Lector bilingüe (Next.js + React + TypeScript + Tailwind).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- ESLint

## Herramientas del proyecto

- **21st.dev (Magic MCP)** — generación de componentes UI, configurado como MCP server (`21st`) con scope local a este proyecto.
- **ECC** (`ecc@ecc`) — plugin de Claude Code con skills/agents/commands para el flujo de desarrollo (planning, TDD, code review, etc.).

## Desarrollo

```bash
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).
