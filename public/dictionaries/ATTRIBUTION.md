# Atribución: en-es.json

Este diccionario (~42.600 lemas) fue generado a partir del dataset
**eng-spa** de [FreeDict](https://freedict.org/), versión `2025.11.23`
(formato StarDict), usando `scripts/build-dictionary.mjs`.

- **Fuente de los datos**: [WikDict](http://www.wikdict.com/), a partir
  de [Wiktionary](https://www.wiktionary.org/) vía
  [DBnary](http://kaiko.getalp.org/about-dbnary/).
